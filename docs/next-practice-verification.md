# 리포트에서 다음 연습 연결

확인일: 2026-11-14.

## 규칙 v1

완료된 기록의 저장된 목표·예정 시간·사용자 부담 응답으로 현재 제안을 계산한다. 위치 품질이나 시연 장면을 운전 실력·안전성으로 해석하지 않는다.

- 응답이 없거나 지원되지 않는 기록은 자동 제안을 만들지 않는다. 사용자는 응답 없이도 직접 연습 조건을 고를 수 있다.
- 회전·교차로에서 ‘부담됐어요’ 응답은 목표를 유지하고 예시 차선 변경 1회 이하 조건을 제안한다. 최대 시간은 30분 이내로 제한하되, 짧은 시간 조건에 맞는 후보가 없으면 빈 결과를 유지한다.
- 차선 변경 준비에서는 목표와 충돌하는 1회 이하 조건을 자동 적용하지 않는다.
- ‘보통이에요’·‘여유 있었어요’ 응답은 같은 목표와 가능한 기존 예시 경로를 유지한다. 목표·난이도를 자동 상향하지 않는다.
- 예상 시간과 코스 속성은 예시 후보에 근거한다. 새 제안이 실제로 더 쉽거나 짧다는 보장은 하지 않는다.
- SDK 기록은 기본 내비의 현재 목적지를 다시 확인하는 화면으로 연결한다. 이전 목적지는 참고로 표시하고, 과거 목적지로 실제 기록을 자동 시작하지 않는다. SDK 목적지 이름을 예시 지도 목적지에 복사하지 않는다.
- DEMO 목적지 기록은 예시 목적지 선택으로 연결한다.
- 제안 적용 전 저장소에서 최신 기록을 다시 읽는다. 부담 응답 저장 중에는 제안 적용 버튼을 비활성화한다. 출발은 별도 사용자 동작이다.

기존 DEMO 리포트의 고정된 ‘회전 경험·감속 장면’ 문구를 저장한 목표·선택 코스 정보로 바꿨다. 원래 기록의 실제 관측 사건인 것처럼 사용하지 않는다.

DB 스키마나 의존성은 변경하지 않았다. 제안은 현재 규칙으로 재계산하며 과거 추천의 스냅샷을 저장하는 기능은 이번 범위에 포함하지 않는다.

## 검증

- 빌드·Lint·단위 테스트 36개 통과. 추가 7개는 미응답·미완료, 부담 조건, 목표 충돌 방지, 기존 경로 유지, 후보 없음, SDK·DEMO 분리, 잘못된 입력을 검증한다.
- 별도 검증 앱에서 미응답 시 자동 제안 없음·직접 조건 설정 진입을 확인했다.
- ‘부담됐어요’ 선택 후 회전 목표·최대 30분·차선 변경 최소화가 연습 설정에 적용되고, 예시 후보 1개와 24분 준비 화면으로 이어지는 것을 확인했다.
- ‘여유 있었어요’로 변경하면 원래 선택한 19분 예시 경로가 제안되는 것을 확인했다.
- DB에서 새 기록의 DEMO/Turns/Direct/예정 19분/저장한 부담 응답을 확인했다. 재실행 후에도 응답과 제안이 일치했고, 이전 기록은 변경되지 않았다.
- 실제 리포트 렌더를 확인했다. SDK 목적지 재조회와 두 번째 SDK 세션의 시작·종료도 후속 [실행 검증](sdk-recording-run.md)에서 확인했다.
