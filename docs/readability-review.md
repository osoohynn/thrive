# Thrive 가독성 수정

검증일: 2026-11-14

현재 운전 적응 화면의 네이티브 렌더를 확인하고 공통 테마와 컨트롤을 수정했다. 차량 시스템 바·테마·글자 배율 설정은 변경하지 않았다.

| 항목 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 글자 위계 | 본문 24sp, 보조 정보 20sp, 고지 18sp | 본문 28sp, 보조 정보 24sp, 고지 22sp. 제목 40~48sp와 굵기 구분 |
| 표면 대비 | 밝은 배경 파형이 패널과 글자에 비침 | 짙은 읽기용 표면과 64% 배경 스크림으로 대비 강화 |
| 선택·입력 | 희미한 외곽선과 색상 중심 선택 표시 | 외곽선 대비 강화, 체크 표시, 키보드 포커스 표시, 입력창 최소 높이 88dp |
| 화면 맥락 | 하위 화면에서 상단 메뉴 선택이 사라짐 | 진입한 홈·연습·기록·프로필 메뉴의 선택 상태 유지 |
| 안내·지도 | 긴 문단의 위계가 약함 | 출발 안내 제목과 설명 분리, 지도 캡션에 배경을 넣고 출발 표시를 피하도록 좌측 상단 배치 |

Android 토큰과 기존 HTML 휴식 미리보기의 대응 토큰, 디자인 시스템 문서를 함께 갱신했다. HTML은 운전 적응 화면의 검증을 대체하지 않는다.

## 확인한 범위

- `assembleDebug lintDebug --offline` 통과. Lint 오류 0개, 기존 `OldTargetApi`·`DataExtractionRules` 경고 2개.
- Pleos API 34, 전체 디스플레이 2560×1440·160dpi, 앱 창 1658×1210에서 실제 렌더 확인.
- 홈·연습·목적지·코스·출발 준비·주행 시연·리포트·기록·프로필·지도 연동 체험과 참여 제안 다이얼로그 확인.
- 연습 목표·시간·코스 선택, 안내 켜기·끄기, 시연 완료와 기록 반영, 프로필 선택·저장, 목적지 반영을 확인했다.
- 기존 HTML 미리보기는 Chromium의 1200·480·320px에서 가로 넘침, 로컬 폰트, 선택·시작·종료·초기화·키보드 포커스를 확인했다.
- 설치 스크립트의 이미지 선택·AVD 생성 및 재사용·실행 실패 처리 검사를 통과했다.

실제 분할 창과 큰 글자 배율에서의 최종 렌더 검증은 남아 있다. 지도 캡션의 마지막 위치 조정은 빌드로 확인했으며, 해당 위치의 설치 후 재촬영은 아직 하지 않았다. 실제 차량·내비게이션·음성 연결은 이번 수정 범위에 포함하지 않는다.
