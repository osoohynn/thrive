# 연습 코스 추천 구현

확인일: 2026-11-14.

## 현재 동작

목표·최대 시간·차선 변경 최소화 조건으로 기존 예시 경로 두 개를 필터링한다. 실제 도로 데이터나 교통 상황으로 생성한 코스가 아니다. 도로 검토와 내비 경로 연결은 후속 작업이다.

- 최대 시간보다 오래 걸리는 예시 경로를 제외한다.
- 회전·교차로 목표는 차선 변경 횟수가 적은 경로를 먼저 제안한다.
- 차선 변경 준비 목표는 변경 구간 2회 이상인 예시만 제안한다.
- 최소화 선택 시 변경 구간 1회 이하로 제한한다. 목표와 충돌하면 빈 결과를 보여준다.
- 결과가 없으면 출발 버튼을 숨기고 조건 수정으로 연결한다.
- 코스 선택 이후 준비 화면과 DEMO 세션에는 실제 선택한 예시 경로·목표·예정 시간을 전달한다. 최대 허용 시간을 코스 소요 시간으로 저장하지 않는다.
- 주행 시작 시 같은 규칙으로 조건과 선택을 재검사한다. 예정 거리와 센서 기반 실제 기록 거리는 구분한다.

이 규칙은 예시 선택 흐름을 구현하기 위한 제품 정책이다. 검증된 운전 교육·도로 안전 기준을 의미하지 않는다. 프로필의 관심 상황을 회피 조건으로 임의 해석하지 않는다.

## 검증

- 빌드·Lint·단위 테스트 24개 통과. 추천 관련 7개 테스트는 시간 경계, 목표별 정렬·제외, 충돌 조건, 빈 후보, 중복 후보, 선택 후 시간·거리 일치를 검증한다.
- 별도 검증 앱(Pleos API 34, 사용자 10)에서 15분 빈 결과, 30분 후보 2개, 차선 목표 후보 1개, 최소화 조건 충돌 시 빈 결과를 확인했다.
- 대안 경로 직접 선택 시 19분·5.9km, 최소 변경 경로 선택 시 24분·6.8km가 준비 화면에 이어지는 것을 확인했다.
- 시연 시작·종료 후 Room에서 `DEMO / Practice / Turns / Gentle / plannedMinutes=24 / Completed`와 실제 기록 경과 시간을 확인했다. 이전 기록은 그대로 유지됐다.
- 추천 화면의 실제 렌더를 확인했다. 실제 도로 추천·기본 내비 경로 연결·교통 반영은 검증 범위에 포함하지 않는다.
