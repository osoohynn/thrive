# Figma 기반 Thrive 다듬기

2026-11-15. 최신 사용자 요청: Figma의 배경과 컬러감을 유지하면서, Apple 디자인은 조금만 참고해 완성도를 높인다. 앞 단계의 기능 중심 제목과 간결한 문구는 유지한다.

## 원본에서 유지한 것

- [배경 `104:17094`](https://www.figma.com/design/V1lYJYRGTstcbi3U6VqEAP/Thrive?node-id=104-17094): 원본 로컬 이미지 두 장, 검정 20%·흰색 20% 합성, wave의 1824/1700 폭과 -93/1700 가로 위치.
- [공통 컴포넌트 `101:8409`](https://www.figma.com/design/V1lYJYRGTstcbi3U6VqEAP/Thrive?node-id=101-8409): Brand `#0F3281`, Mint `#93E8EE`, Text `#0B1424`, TextSecondary `#1C3C52`. 선택 카드 Mint 18%, 선택 칩 Mint 35%, 내비게이션의 반투명 흰색 표면.
- [홈 `104:17089`](https://www.figma.com/design/V1lYJYRGTstcbi3U6VqEAP/Thrive?node-id=104-17089): 목적지/연습 카드의 845:611 비율과 로컬 아이콘. 최신 원본의 추가 대시보드 구성은 이번 배경·스타일 조정에 새 기능으로 확장하지 않았다.

위 노드의 최신 디자인 컨텍스트와 스크린샷을 다시 확인했다. 화면 스크린샷을 UI 자산으로 사용하지 않는다.

## 절제해서 조정한 것

[Apple HIG의 Materials](https://developer.apple.com/design/human-interface-guidelines/materials)와 [Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles/)에서 표면의 위계, 정보의 가독성, 일관된 반응을 참고했다. Android Compose 구현이며 Apple의 재질 API나 Liquid Glass를 구현했다고 표현하지 않는다.

| 요소 | 현재 조정 |
| --- | --- |
| 읽는 패널 | 흰색 92%를 단일 Box 배경으로 그림. 내부의 중복 배경 제거. 홈 카드 세 곳에만 3dp의 약한 바깥 그림자를 사용하고 나머지 패널은 그림자 없음. |
| 내비게이션 | 128dp 폭의 연결형 바. 투명 표면, 회색 선택 영역. 외곽선·그림자 없음. 항목 간격 8dp. 민트 바탕색 제거. 비선택 아이콘 검정, 선택 아이콘 네이비. 키보드 포커스만 2dp. |
| 제목 | 기존 40/32/28sp와 Pretendard 유지, 자간만 -0.4/-0.2/-0.1sp로 정돈. 본문은 축소하지 않음. |
| 버튼·칩 | 16dp 반경과 64dp 이상 터치 높이 유지, 회색/밝은 파랑을 원본의 네이비·민트 역할색으로 교체. |
| 문구 | 기능명·값·필요한 동의·오류 안내 유지. 감성 문구와 반복 설명을 다시 넣지 않음. |
| 모션 | 기존 누름·선택·토글·화면·다이얼로그 반응 유지. 모션을 기다리느라 입력이나 저장을 지연하지 않음. |

배경 위에 추가 그라데이션·장식 그림을 얹지 않고, 패널을 여러 겹 투명하게 쌓거나 전체 화면 blur를 추가하지 않는다. 주행 시 커스텀 모션을 차단하고 모션 줄이기 설정을 유지한다.

## 검증

- 최종 `testDebugUnitTest assembleDebug --offline`: 빌드 성공, 단위 테스트 59개 통과(실패·오류 0).
- `nav_ui`: 연결형 내비바의 탭 전환 14개, 선택 상태·대상 페이지, 빠른 연속 전환, 세로·600dp 가로 배치 통과. 이후 변경은 민트 바탕색 제거와 홈 카드 그림자 등 시각 스타일에 한정한다.
- `git diff --check` 통과.
- 원본 배경 두 장의 로컬 파일과 합성 위치를 유지한다. 이전 중립색 테마의 `docs/ui/2026-11-15/` 캡처는 이전 단계 기록이며 현재 디자인의 최종 렌더로 제시하지 않는다.
- 마지막 색상·그림자 조정 후 전체 화면 렌더 검토는 다시 수행하지 않았다. 사용자의 요청에 따라 현재 상태를 커밋 시점으로 확정한다.
